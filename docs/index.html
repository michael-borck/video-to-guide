How it works

1 · Record

Show the task

Make a plain screen recording, the kind you would send a colleague. Drop it in a project folder as video.mp4. No script, no rehearsal.

2 · Capture

Pick the frames

Scene detection proposes sharp, distinct frames. Scrub the timeline and capture your own when you want something else. Redact anything private before it ships.

3 · Organise

Write the steps

Group frames into sections and caption each step. Record narration and the app will suggest text from it, using local transcription. You always have the last word.

4 · Export

Share the guide

One click produces a styled HTML page and a PDF, images included. Each export replaces the last, so removed steps never haunt the output.

Good to know

PDF needs a browser

PDF export renders through a local headless Chrome. Google Chrome, Chromium, or Edge installed on your machine is all it takes. HTML export has no requirements.

Transcription is optional

Suggestions from narration use faster-whisper running locally. The model downloads the first time you use it; skip the feature entirely and nothing extra installs.

Open source

MIT licensed, and the Python package is on PyPI. Prefer terminals? The same pipeline runs from source with a few commands.

Run it from source

No installer required. You need Python 3.12+, uv, and Node.js for the frontend build. 

git clone https://github.com/michael-borck/video-to-guide
cd video-to-guide
uv sync
cd frontend && npm install && npm run build && cd ..
uv run uvicorn backend.main:app
